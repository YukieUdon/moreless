# 隐私说明

最后更新：2026-10-18

「多少 / moreless」是一个**本地优先**的小工具。这一页说明 App 会碰哪些数据、存在哪里、怎么删。

## 一句话

不注册、不登录、不联网、不推送、不做用户分析。收支和设置只存在你自己的设备上。

## 会存什么

App 只在本机保存两类数据：

| 数据 | 存储位置 | 内容 |
|---|---|---|
| 收支 | AsyncStorage `ml_plan_v2`（旧版 `ml_plan_v1`） | 收入、支出条目、周期、假期开关 |
| 设置 | AsyncStorage `ml_settings_v1` | 主题、换算页默认显示方式 |

这些数据**不会上传到任何服务器**。App 没有账号系统，也没有云端同步。

## 不会做什么

- 不收集姓名、手机号、邮箱、位置、通讯录、照片等个人信息。
- 不接入广告 SDK、统计 SDK、崩溃上报 SDK。
- 不读取银行、支付宝、微信账单。
- 不申请通知、相机、麦克风、定位等权限。
- 不向第三方出售或共享数据。

## 怎么删除

- 在 App 里打开「我的 → 清空收支数据」，会删掉本机的收支记录（设置偏好保留）。
- 卸载 App 会删除该 App 的全部本地数据。
- 删除后无法恢复。

## 主动打开的链接

「我的 → 源代码」会用系统浏览器打开 GitHub 仓库。这是你主动点击的，不会附带任何收支、设置或设备信息。

## 开发模式说明

用 Expo Go 扫码开发时，手机上的 Expo Go 会连接你电脑上的 Metro 开发服务器；这是开发工具的行为，不是这个 App 的业务逻辑。装成独立安装包后，App 不发起网络请求。

## 儿童

本 App 不面向儿童收集任何信息，也不包含账号或社交功能。

## 变更

如果以后加入云同步、账号或任何联网功能，会先更新这份说明，并在 README 和 Release Notes 里写明。
